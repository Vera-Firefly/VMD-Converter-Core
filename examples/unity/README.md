# Unity Editor integration

## Installation

Install `com.verafirefly.vmdcc/` from the release as a local Unity package. The package includes C# invocation scripts, assembly definitions, Unity metadata and external binaries under `Tools/`. It supports Unity 2022.3 on Windows x64 and can be used independently of VMDCW and VRCSDK.

Reference `com.verafirefly.vmdcc` and `com.verafirefly.vmdcc.editor` from your Editor assembly definition. Add `com.verafirefly.vmdcc.nlu.editor` when using `VmdNluBatchPipeline` directly.

## Create clips from curve caches

Copy [VmdccTargetFkExample.cs](VmdccTargetFkExample.cs) and its `.asmdef` into `Assets/Editor/`, or add the C# file to your own Editor assembly:

```csharp
IReadOnlyList<AnimationClip> clips = VmdccTargetFkExample.Convert(
    targetAvatarGameObject,
    @"C:\Project\Packages\com.verafirefly.vmdcc\Tools\VmdConverterCore.exe",
    @"C:\Motions\model.pmx",
    new[] { @"C:\Motions\a.vmd", @"C:\Motions\b.vmd" },
    "Assets/Dance", sampleRate: 30f, threads: 8);
```

The target must have a valid imported Humanoid Avatar with a Hips mapping. The output Assets folder must already exist. The example refuses to overwrite existing clips. PMX, VMD and executable paths are physical file paths.

The example exports the target rig once, converts the batch in one process, reads each curve cache and creates target FK clips. For Humanoid output, set `VmdRigExportOptions.OutputKind` to `HumanoidIk` or `TargetCalibratedHumanoid`, export the rig, call `AttachCanonical` with the canonical PMX Humanoid rest-pose GameObject, then save with `WriteJson`. Use `PrepareBatch(..., noUnity: true)` or `VmdNluBatchPipeline.PrepareBatch` for standalone Humanoid curve solving.

## Generate .anim externally

`VmdStandaloneAnimConverter` passes paths and conversion options to the EXE. Use `VmdSourceFbxUtility.FindSourceFbx` when starting from a Unity GameObject:

```csharp
using UnityEditor;
using VeraFirefly.VmdConverter.Core;
using VeraFirefly.VmdConverter.Core.Editor;

var options = new VmdStandaloneAnimOptions {
    ExecutablePath = exePath,
    PmxPath = pmxPath,
    FbxPath = VmdSourceFbxUtility.FindSourceFbx(targetGameObject),
    OutputKind = VmdExternalOutputKind.TargetCalibratedHumanoid,
    Threads = 8
};
var jobs = new[] {
    new VmdStandaloneAnimJob { VmdPath = firstVmd, OutputPath = firstPhysicalAnim },
    new VmdStandaloneAnimJob { VmdPath = secondVmd, OutputPath = secondPhysicalAnim }
};
string command = VmdStandaloneAnimConverter.BuildCommandLine(options, jobs[0]);
VmdStandaloneAnimConverter.ConvertBatch(options, jobs);
AssetDatabase.ImportAsset(firstAssetAnim, ImportAssetOptions.ForceSynchronousImport);
AssetDatabase.ImportAsset(secondAssetAnim, ImportAssetOptions.ForceSynchronousImport);
```

Use absolute physical paths for conversion. `firstAssetAnim` and `secondAssetAnim` are the corresponding `Assets/...` paths. Files must be under Assets before calling `ImportAsset`. Scene skeleton edits are not automatically exported to the source FBX.

Set `ExpressionVmdPath` for facial motion and `MorphMapPath` for a mapping file generated by `WriteMorphMap`. Unmapped morphs use `Body`. The worker replaces existing output files after a successful write, so implement the desired overwrite policy in the host.

This bridge passes `--anim-w`; offline FBX/PMX rig generation requires the HPS adapter/SDK. `PrepareBatch` and `--nlu` retain the VMDCC rig format and solver. See [the CLI guide](../../docs/OFFLINE.md) for parameters.

## Public entry points

| API | Purpose |
| --- | --- |
| `VmdTargetRigExporter.Export/ExportJson/AttachCanonical/WriteJson` | Export a Unity-imported target rig and its Humanoid calibration. |
| `VmdConverterCore.PrepareBatch` | Invoke the external converter for a batch. Dispose the returned batch after reading its caches. |
| `VmdExternalPoseBatch.GetPosePath` | Resolve a VMD's cache file. |
| `VmdConverterCore.ReadCurves` | Read and verify the curve cache against PMX, VMD and rig identities. |
| `VmdNluBatchPipeline.PrepareBatch` | Invoke standalone RootMotion/Muscles conversion. |
| `VmdStandaloneAnimConverter.BuildCommandLine/ConvertBatch/WriteMorphMap` | Generate commands, batch `.anim` output and morph mappings. |
| `VmdSourceFbxUtility.FindSourceFbx` | Resolve an imported GameObject to its source FBX. |

Rig export, `AnimationUtility` and `AssetDatabase` operations belong in Editor assemblies. The external process handles pose solving. See [the integration call chain](VMDCW_CALL_CHAIN.md) for source locations.
